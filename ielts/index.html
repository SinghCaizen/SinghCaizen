        Account

        Cloud sync ruka hua hai — Firestore rules purane hain. Fix (2 minute):

        1. console.firebase.google.com kholo → project singhcaizenfinance chuno.
        2. Left menu: Build → Firestore Database → Rules tab.
        3. Purana text hata kar ye paste karo aur Publish dabao:
        rules_version = '2';
        service cloud.firestore {
          match /databases/{database}/documents {
            match /users/{uid}/{document=**} {
              allow read, write: if request.auth != null && request.auth.uid == uid;
            }
          }
        }

        Ye rules Folio ko bhi waise hi chalate hain (har user sirf apna data). Publish ke baad page refresh karo — "Synced ✓" dikhne lagega.

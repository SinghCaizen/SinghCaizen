            👤 Account

            ☁️ Cloud Sync setup — exact steps (ek baar karna hai)
            1. Apne phone/computer par console.firebase.google.com kholo, apne Google account se sign in karo.
            2. "Add project" (ya "Create a project") dabao → naam do: ielts-study → Google Analytics band karke Create project.
            3. Project khulne par left menu me Build → Authentication → Get started.
            4. Sign-in method tab me pehle Email/Password ko Enable karo, phir Google ko bhi Enable karo (apna email chun kar Save).
            5. Usi page par neeche Settings → Authorized domains me singhcaizen.github.io add karo.
            6. Left menu me Build → Firestore Database → Create database → Start in production mode.
            7. Firestore ke Rules tab me purana text hata kar ye paste karo aur Publish dabao:
              rules_version = '2';
              service cloud.firestore {
                match /databases/{database}/documents {
                  match /users/{uid}/{document=**} {
                    allow read, write: if request.auth != null && request.auth.uid == uid;
                  }
                }
              }
            8. Project Overview (home) par </> Web app icon dabao → app ka naam ielts-web → Register app. Waha ek firebaseConfig dikhega.
            9. Us config ki values Noor ko bhej do (ye public hoti hain, secret nahi) — mai firebase-config.js me daal kar site update kar dungi. Ya khud GitHub par file edit karke paste kar do.
            10. Bas! Phir site par Sign Up karke account banao — progress cloud me save hone lagegi.

# Media folder

Apni khud ki files yaha rakho aur `data/chapters.js` me unka path do:

- `media/audio/` — .mp3 audio files, path jaise `media/audio/test-1.mp3`
- `media/video/` — .mp4 / .webm video files, path jaise `media/video/lesson-1.mp4`
- `media/pdf/` — .pdf files, path jaise `media/pdf/book.pdf`

Filhaal saara study material Google Drive se website ke andar hi chalta hai,
isiliye ye folders khaali hain — jab chaaho apni files yaha daal sakte ho.

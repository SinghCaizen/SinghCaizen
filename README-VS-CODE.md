scroll animations, slow hero zoom, animated counters, sticky shrinking header.

## How YOU run it in VS Code (only 3 steps)
1. Download & unzip `singh-caizen-website.zip`, then in VS Code: File > Open Folder > select the `singh-caizen-website` folder.
2. Install the free extension **Live Server** (by Ritwick Dey) from the Extensions tab (Ctrl+Shift+X) — one time only.
3. Open `index.html`, right-click anywhere in the code > **Open with Live Server**. Site opens in your browser. Click the top menu to check all 7 pages.

No internet package, no npm, no build step needed. Editing any file + saving = browser auto-refreshes.
